# To-Do List

## Overview

A simple to-do list web application built with HTML, CSS, and vanilla JavaScript. Users can type a task and add it to the list, which is displayed dynamically on the page.

## Assignment

The task was to build a to-do list using JavaScript. The app had to include:

- An input field and an "Add" button for creating new tasks
- A task list that updates dynamically when a task is added

The goal of the assignment was to practice JavaScript fundamentals, including selecting elements, handling form events, and updating the page with DOM manipulation.

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Sarah-SWE/Todo-List-using-js.git
cd Todo-List-using-js
```

Open `htTo-Do.html` in any web browser. No installation or build step is required.
